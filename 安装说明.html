RWTH SUPERC · v0.3.1

解压后加载，准备你的下一次 Termin。

Chrome / Edge 浏览器扩展。无需安装 Node.js、Python 或登录 Telegram。

安装

  1. 解压 ZIP，并保留解压后的文件夹。
  2. Chrome 地址栏打开 chrome://extensions；Edge 打开 edge://extensions。
  3. 打开开发者模式，点击加载已解压的扩展程序。
  4. 选择解压后的 extension 文件夹，里面直接包含 manifest.json。
  5. 从扩展菜单打开RWTH SuperC Termin 助手，填写资料和时间条件，点击保存。
  6. 测试铃声，检查自动提交设置，再点击开始监测。

这是 ZIP 扩展安装包，需要加载文件夹，没有 EXE 安装程序。最低 Chrome 120。已有旧版请覆盖原 extension 文件夹后“重新加载”，无需卸载。

运行方式

监测最早时间 → 确认一次选时弹窗 → 自动填普通资料 → 你完成验证码和同意项 → 核对并自动提交一次 → 你确认邮件。

保持电脑、浏览器和官网标签页运行。关闭设置页不影响监测；关机、休眠或退出浏览器后无法监测。

用户反馈已自动到达真实验证码页面，不代表最终预约或所有官网页面均已实测。以官网和确认邮件为准。

可选截图与隐私

遇到需要接手的情况会保留本地诊断。截图需在设置页另行启用；Chrome 会要求可选“所有网站”权限，代码只截图绑定的官方预约页并在前后核对。

最近最多 6 条，可下载 JPG 与 JSON。截图可能含表单资料和验证码，请检查遮盖后分享。扩展没有项目服务器，不上传截图或资料；本地存储未额外加密。

适用范围

独立个人辅助工具，非官方产品。只适用于 RWTH Studenten / SuperC；请先核实官网分类要求。工具不识别验证码或勾选声明，无法保证获得预约。
