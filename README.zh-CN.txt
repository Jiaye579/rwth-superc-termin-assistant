================================

安装（Chrome / Edge，无需 Node.js、Python 或 Telegram）
-----------------------------------------------------
1. 解压安装 ZIP，保留解压后的文件夹。
2. Chrome 地址栏打开 chrome://extensions；Edge 打开 edge://extensions。
3. 打开“开发者模式”，点击“加载已解压的扩展程序”。
4. 选择解压后的 extension 文件夹。它里面应直接包含 manifest.json。
5. 从扩展菜单打开“RWTH SuperC Termin 助手”，填写姓名、邮箱、电话、出生日期和时间条件，保存。
6. 测试铃声，检查自动提交设置，再点击“开始监测”。

这是 ZIP 扩展安装包，需要解压后加载文件夹，没有 EXE 安装程序。
最低 Chrome 120，使用支持 Manifest V3 的 Chrome / Edge。

使用
----
- 默认每 60 秒检查并增加少量随机等待；符合条件时选择最早时间。
- 选时后按受支持弹窗内实际位置，自动点击右侧蓝色继续按钮一次，再填普通资料。
- 验证码由你填写，同意项由你阅读勾选。完成并移出验证码输入框后，助手核对并自动提交一次。
- 官网可能要求确认邮件，须你及时打开确认链接；以官网和邮件为准。
- 铃声可持续 2 分钟或直到手动关闭；无号时保持安静。
- 电脑、浏览器和官网标签页须保持运行。设置页可以关闭，关机或休眠无法监测。
- 如请求结果不明，先核对官网与邮箱，不要重复预约。

更新
----
将新版 extension 内的文件覆盖原先加载的文件夹，在扩展管理页点“重新加载”，重新打开设置并保存。
无需卸载旧扩展；卸载会清除浏览器内保存的数据。新版脚本在新加载的官网页面生效。

可选截图与隐私
--------------
“卡住时自动留档”记录页面步骤、字段结构、按钮和原因，仅存在本地浏览器。
点击“启用自动截图”并授予可选权限后，才会保存原生截图；Chrome 会显示“所有网站”授权。
截图实现只处理本轮绑定的外管局官网页，并在截图前后核对，正常无号检查不截图。
最近最多 6 条，可下载 JPG 和 JSON；容量到上限时可能少于 6 条。
截图可能含姓名、邮箱、电话和验证码，分享前请遮盖；不要公开上传原始诊断。
可撤销截图授权；“清除扩展内资料和诊断截图”会停止监测并清除本地资料和诊断。
扩展没有项目服务器，不向 Telegram 或其他服务上传资料；本地存储未额外加密。

适用范围与验证
--------------
独立个人辅助工具，非 RWTH 或外管局官方产品；只适用于 RWTH Studenten / SuperC。
